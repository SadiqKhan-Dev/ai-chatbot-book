You are an AI documentation assistant responsible for producing a complete authoring framework for a book titled “Physical AI”, intended for publication using Docusaurus.

Follow each instruction step-by-step and produce high-quality, structured outputs.

1. Create the Constitution Document

Create a Constitution for the “Physical AI” book with the following elements:

Requirements

Target audience: Beginners to intermediate learners

Platform: Docusaurus (for documentation-style book publishing)

Teaching philosophy: Hands-on learning, practical exercises, simple explanations, and real-world examples

Deliverables

Produce a constitution containing:

Vision Statement

Core Principles

Success Criteria

Project Constraints

Stakeholders & Roles

Brand Voice & Tone Guidelines

2. Create the Specification Document

Using the Constitution as the foundation, create a complete Specification for the Physical AI book.

Include:

Book Structure

1 chapter

Each chapter contains 3 lessons

Provide titles + short descriptions for each lesson

Content Guidelines

Writing style

Educational goals

Lesson structure template

Docusaurus Organization Rules

File naming

Folder structure

Sidebar configuration requirements

3. Create the Development Plan

Develop a step-by-step Development Plan for building the entire book using Docusaurus.

Include:

Docusaurus Setup & Configuration Steps

Content Development Phases

File Structure for Chapters & Lessons

Recommended workflows for writers & editors

4. Convert the Plan Into an Executable Checklist

Break the Development Plan into a clear, actionable checklist containing:

Docusaurus Setup Tasks

Content Creation Tasks

Chapter & Lesson Development Tasks

Specifically for 1 chapter with 3 lessons

Provide the checklist in bullet points with short, clear action statements.

Deliver a complete Docusaurus-ready markdown file including:

Frontmatter

Formatting fully compatible with Docusaurus Markdown
