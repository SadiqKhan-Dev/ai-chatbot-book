# Isaac Sim & Nav2 Navigation

Welcome to Module 3 of the Physical AI & Humanoid Robotics course. This module covers NVIDIA Isaac Sim for robot simulation and ROS 2 Nav2 for autonomous navigation.

## Overview

Learn to create realistic navigation simulations using NVIDIA Isaac Sim and implement autonomous navigation with ROS 2 Nav2.

## Chapters

1. **Isaac Sim Synthetic Data** - Generate training data in simulation
2. **Isaac ROS Perception** - Computer vision in ROS 2
3. **Nav2 Bipedal Navigation** - Humanoid robot path planning

## Prerequisites

- Completion of Modules 1 & 2
- Basic understanding of ROS 2
- Familiarity with navigation concepts

## Estimated Time

5 hours
