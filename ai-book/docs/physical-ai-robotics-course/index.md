# Module 2: Digital Twin (Gazebo & Unity)

Create simulation-only digital twins of humanoid robots using Gazebo and Unity.

## Learning Objectives

By completing this module, you will be able to:

1. **Create** humanoid robot models in Gazebo using URDF/XACRO formats
2. **Configure** humanoid robots in Unity using physics components
3. **Implement** realistic sensor models (camera, LiDAR, IMU) in both platforms

## Chapters

| Chapter | Topic | Estimated Time |
|---------|-------|----------------|
| 1. Gazebo Fundamentals | URDF, XACRO, physics plugins | 6 hours |
| 2. Unity Fundamentals | PhysX, character controllers | 4 hours |
| 3. Sensor Simulation | Camera, LiDAR, IMU in both | 6 hours |

**Total**: 16 hours

## Prerequisites

- Basic programming (Python, C#)
- Understanding of 3D coordinate systems
- See [Prerequisites](./prerequisites.md) for full details

## Success Criteria

| Criterion | Target |
|-----------|--------|
| Create Gazebo humanoid | 45 minutes |
| Create Unity humanoid | 45 minutes |
| Configure 3+ sensor types | Demonstrable |

## Exclusions

- Hardware integration
- Learning algorithms
- Navigation systems
