# Module 1: ROS 2 & URDF Fundamentals

Master ROS 2 as a robotic middleware and create URDF descriptions for humanoid robots.

## Learning Objectives

1. Understand ROS 2 architecture and DDS communication
2. Create ROS 2 nodes, topics, and services using rclpy
3. Integrate Python AI agents with ROS 2 controllers
4. Build URDF models for humanoid robot structures

## Structure

| Section | Topic | Time |
|---------|-------|------|
| 1. ROS 2 Nervous System | Architecture & concepts | 2 hrs |
| 2. Communication Primitives | Nodes, topics, services | 3 hrs |
| 3. Python Agent Integration | rclpy & agent patterns | 2.5 hrs |
| 4. URDF Humanoid Modeling | Robot description | 2.5 hrs |

**Total**: ~10 hours

## Prerequisites

- Basic Python programming
- Command-line familiarity
- See [Prerequisites](./prerequisites.md)
